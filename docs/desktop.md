# Desktop-клиент (vkturn-desktop)

## Что это

`vkturn-desktop` — терминальный клиент для родни: логин по учётке портала
(`lft.levnas.ru` или другого, см. переменную окружения ниже) вместо ручной
правки конфигов. После входа показывает меню с тремя рабочими режимами
(`vk-turn (socks)` — свой TURN-туннель за локальным SOCKS5-мостом,
`vk-turn (tun)` — тот же туннель, но на весь трафик машины через системный
TUN-интерфейс, `xray-подписка` — обычная xray-подписка) и сам поднимает
нужные локальные процессы. Заменяет ручные наборы вроде
`win-kit2`/`vkturn-linux-kit` там, где технарь может настроить портал заранее.

## Как получить

Скачайте один файл `vkturn-desktop-<платформа>` со страницы релизов:
`https://github.com/samosvalishe/free-turn-proxy/releases/latest`
— например `vkturn-desktop-windows-amd64.exe` или
`vkturn-desktop-linux-amd64`. Переименовывать необязательно, но для ярлыка
удобнее переименовать в `vkturn-desktop.exe`/`vkturn-desktop`. Больше ничего
скачивать и раскладывать по папкам не нужно: `client` и `xray` (и на Windows
`wintun.dll`) вшиты внутрь этого файла и при первом запуске сами
распаковываются в `~/.vkturn/bin/`.

## Запуск

При первом запуске `vkturn-desktop` спросит логин и пароль от портала
(пароль не отображается на экране при вводе). После успешного входа конфиг
кешируется локально (`~/.vkturn/config.json`), при следующих запусках
повторный вход не нужен.

Портал по умолчанию — `https://lft.levnas.ru`; переопределяется переменной
окружения `VKTURN_PORTAL_URL`, если нужно указать другой адрес (например,
при недоступности основного).

Дальше — меню со стрелками (`↑`/`↓`, `Enter` — выбрать):

- **vk-turn (socks)** — поднимает `client` (TURN-туннель), затем локальный
  xray-мост, проверяет соединение (запрос выходного IP) и печатает
  `Подключено, выходной IP: <ip>` при успехе. Прокси доступен на
  `socks5://127.0.0.1:1085` — укажите его в браузере/приложении.
- **vk-turn (tun)** — тот же TURN-туннель, но без ручной настройки прокси в
  приложениях: xray-core поднимает системный TUN-интерфейс, и в туннель
  уходит весь трафик машины, кроме LAN/приватных диапазонов. Требует права
  администратора/root — `vkturn-desktop` сам запрашивает повышение
  (UAC на Windows, `pkexec` на Linux) при выборе этого пункта, вручную
  запускать от администратора не нужно. На Windows `wintun.dll` доставать
  не нужно — он вшит в `vkturn-desktop.exe` вместе с `client`/`xray` и
  распаковывается вместе с ними. macOS пока не поддерживается — только
  Windows и Linux.
- **xray-подписка** — забирает вашу xray-подписку с портала, конвертирует
  первый пригодный конфиг и запускает `xray` напрямую.
- **обновить конфиг** — повторный логин, если данные на портале изменились.
- **выход** — завершение программы.

`Ctrl+C` останавливает текущий режим и возвращает в меню (или завершает
программу, если нажать на самом меню).
